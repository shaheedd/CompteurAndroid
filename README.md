# Compteur Android

Application mobile Android native implémentant un compteur interactif simple et intuitif.

## Fonctionnalités
- Affichage de la valeur courante du compteur.
- Bouton `+` pour incrémenter la valeur.
- Bouton `-` pour décrémenter la valeur.
- Bouton `Réinitialiser` pour remettre le compteur à 0.
- Bouton supplémentaire affichant un message `Toast`.

## Technologies
- **Langage** : Kotlin
- **Interface** : XML Layout (LinearLayout, Material Design)
- **SDK** : Min SDK 24 / Compile & Target SDK 37
- **Outil de build** : Gradle (Kotlin DSL)

## Installation et exécution
1. Cloner le dépôt :
   ```bash
   git clone https://github.com/shaheedd/CompteurAndroid.git
   ```
2. Ouvrir le projet dans **Android Studio**.
3. Laisser Gradle synchroniser les dépendances.
4. Lancer l'application sur un émulateur ou un appareil physique connecté.
